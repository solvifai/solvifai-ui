# SolvifAI UI ガイド

SolvifAI v2のモックや新機能のUIに、[UIカタログ](https://solvifai.github.io/solvifai-ui/)を使う。

1. 画面の目的と主操作を先に決める。保存や作成など、同じ操作のまとまりの中で最優先の操作に AppButton の primary を使う。
2. ボタン、検索、入力、セレクトボックス、チェックボックス、状態表示、確認ダイアログは、カタログで用途と利用例を確認してから選ぶ。
3. 色・文字・境界線は既存のデザイントークンを使う。状態は色と文言で示す。
4. 入力欄にラベルを付ける。入力エラーには原因と修正方法を表示する。検索0件とデータ未作成では次にできる操作が伝わる文言を使う。
5. 操作はキーボードでも行えるようにする。フォーカスが見えることと、ダイアログを閉じると開いたボタンに戻ることを確認する。
6. レビューでは、該当コンポーネント名と確認した状態を共有する。カタログにない共通パターンは、その利用箇所と必要な状態を添えて提案する。

## AIに渡すテンプレート

SolvifAI v2の画面モックを作成してください。
https://solvifai.github.io/solvifai-ui/ のコンポーネントとデザイントークンを使ってください。
画面の目的と主操作を明示し、関連する入力エラー、読み込み、空の状態も用意してください。
使ったコンポーネント名と、追加で必要な共通UIがあればその用途を最後に示してください。
